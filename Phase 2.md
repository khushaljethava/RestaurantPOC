# What the product is

Cross-stall POS and settlement for food courts and standalone stalls:

- Stall-as-tenant tenancy and food court groups
- Menu, staff, orders, bills, cash/UPI payment
- Stall order screen + digital receipts
- Settlement and sales reporting

See Phase 1 and the design spec for the active scope. There is no Phase 2 feature set beyond that.
